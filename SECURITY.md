# Política de segurança

## Versões suportadas

Enquanto o projeto estiver na série `0.1.x`, correções de segurança serão aplicadas somente à versão mais recente disponível na branch principal.

## Relatar uma vulnerabilidade

Não abra uma issue pública com detalhes de uma vulnerabilidade. Use a opção **Report a vulnerability** na aba **Security** do repositório para enviar um relatório privado.

Inclua, quando possível:

- componente e versão afetados
- passos para reproduzir o problema
- impacto observado ou potencial
- sugestão de correção

O recebimento será confirmado em até sete dias. A análise, a correção e a divulgação serão coordenadas pelo mantenedor de acordo com a gravidade.

## Escopo

O PDV Local escuta em `127.0.0.1` por padrão e foi projetado para uso em uma máquina controlada. Expor a API diretamente à internet não é uma configuração suportada.
